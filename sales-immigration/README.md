# Portfolio — Sara Alves (Sales, Immigration & Relocation)

Third portfolio variant: English only, positioning Sara as a **sales professional targeting the
immigration/relocation niche**, with real case-management experience as her core differentiator.

- `index.html` — main page
- `case-roots-onboarding.html` — Roots Global case study, reframed toward the eligibility/onboarding
  call (the moment closest to a sales conversation)
- `assets/` — photo and testimonial screenshots, including the new one from Lin Hove

## Publishing on GitHub Pages

Independent site. Two ways to publish:

1. **New repository**: create a third repo, upload these 2 `.html` files + `assets`, enable Pages.
2. **Subfolder in the existing repo**: create e.g. `/sales-immigration` inside `allvessara.github.io`
   and upload the files there. It will live at
   `https://allvessara.github.io/sales-immigration/`.

## The core narrative

The hero, a new "The Pivot" section, and several bullet points across Experience make the
positioning explicit: Sara spent 2+ years inside real immigration case management, and is now
moving into sales — bringing product knowledge, trust-building and objection-handling that come
from having actually done the job, not from a script. This is stated honestly: it does not claim
prior sales job titles, only that the skills and product knowledge transfer directly.

## Color palette

- Navy `#1F2A44` — primary accent (headings, big numbers, buttons, the tag marquee background)
- Warm Beige `#E8DCC8` — main page background (replacing the previous off-white)
- Soft Gold `#C6A75E` — secondary accent (decorative highlights, selection color, and — on the case
  study's dark header — the emphasis color, which pairs nicely with navy)
- White card backgrounds throughout, for contrast against the beige page

The hero's rotating word ("the process" / "the paperwork" / "real cases") now uses the same serif
weight as the rest of the headline (no italic), keeping only the navy color for emphasis, as
requested.
